# Dynamic Calculator

A simple C++ console-based calculator that performs basic arithmetic operations based on user input.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Decimal number support
* Division-by-zero error handling
* Invalid operation handling

## How It Works

The program asks the user to enter two numbers and an arithmetic operator (`+`, `-`, `*`, or `/`). It then performs the selected calculation and displays the result.

### Example

```text
==============================

      DYNAMIC CALCULATOR

==============================

Enter Number 1:
10
Enter Number 2:
5
Enter the operation you want to perform:
*

The Multiplication of 10 and 5 is: 50


========================================
       Calculation Successful!
  Thank you for using Dynamic Calculator.
========================================
```

## Technologies Used

* C++

## Purpose

This project was created as a C++ practice project to strengthen programming fundamentals, including variables, user input, conditional statements, arithmetic operators, and basic error handling.
